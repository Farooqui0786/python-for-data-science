## 📂 Repository Structure

The repository contains **13 folders** organized by topics and projects:

### 1️⃣ Python Basics
- Core Python concepts for data analysis.
- Variables, loops, conditionals, functions, lists, dictionaries, and sets.

### 2️⃣ Intro to Pandas
- Introduction to Pandas library.
- Creating and using **Series** and **DataFrames**.
- Basic data inspection: `head()`, `info()`, `describe()`.

### 3️⃣ Project 1 – Web Scraping with Pandas
- Extracting data from websites using `requests` and `BeautifulSoup`.
- Loading and analyzing scraped data in Pandas.

### 4️⃣ Filtering
- Selecting rows and columns.
- Conditional filtering and slicing data.

### 5️⃣ Data Extraction
- Extracting specific information from datasets.
- Techniques for selecting and retrieving meaningful subsets of data.
- Examples include extracting columns, filtering rows based on conditions, and working with text or numeric data.

### 6️⃣ Pivot Tables
- Summarizing data using pivot tables.
- Aggregation with `sum()`, `mean()`, `count()`, etc.

### 7️⃣ Project 2 – Data Visualization
- Visualizing datasets using **Matplotlib** and **Seaborn**.
- Line plots, bar charts, histograms, heatmaps, and pair plots.

### 8️⃣ GroupBy & Aggregate Functions
- Grouping data with `groupby()`.
- Aggregating using sum, mean, count, and custom functions.

### 9️⃣ Merging & Concatenating DataFrames
- Combining multiple DataFrames using `merge()` and `concat()`.
- Inner, outer, left, and right joins.

### 🔟 Regular Expressions
- Cleaning and extracting text data using Python `re`.
- Examples: emails, phone numbers, patterns in text columns.

### 1️⃣1️⃣ Project 3 – Data Cleaning with Pandas
- Handling missing data: `dropna()`, `fillna()`.
- Removing duplicates, correcting inconsistent formats.

### 1️⃣2️⃣ Machine Learning Basics
- Intro to machine learning concepts.
- Using Pandas for preprocessing datasets before modeling.

### 1️⃣3️⃣ Project 4 – Text Classification
- Applying machine learning on text datasets.
- Preprocessing text, vectorization, model training, and evaluation.
- **Dataset:** [IMDB Dataset of 50K Movie Reviews](https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews) on Kaggle.
